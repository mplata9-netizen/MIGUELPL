PLANTILLA BASE — HERO BANNER PARA ADAPTAR A CLIENTE

ARCHIVOS
index.html
css/styles.css
js/script.js
assets/images/modelo-principal.webp
assets/images/duenos.webp

QUÉ DEBE CAMBIAR EL ESTUDIANTE

HTML
- Nombre del cliente.
- Título.
- Subtítulo.
- Descripción.
- Botones.
- Menú.
- Datos del panel inferior.
- Texto de dueños/equipo.
- ALT de las imágenes.

IMÁGENES
- Retocar una imagen principal.
- Quitar fondo cuando lo requiera el diseño.
- Exportarla como modelo-principal.webp.
- Retocar la fotografía de dueños/equipo.
- Exportarla como duenos.webp.
- Reemplazar los archivos dentro de assets/images/.

CSS
- Modificar primero las variables de :root.
- Cambiar --accent y --accent-2 según la identidad visual.
- Ajustar fondos, sombras y tipografía.
- Ajustar tamaño/posición de la imagen si es necesario.

JAVASCRIPT
- Puede conservarse.
- Si cambian el color principal, también pueden cambiar el RGB
  de las partículas dentro de script.js.

PUBLICACIÓN
La estructura está lista para GitHub Pages.
index.html debe permanecer en la raíz del repositorio.
